## 怎麼改內容
1. 改 `src/` 底下的零件（不要直接改輸出的 HTML）：
   - `src/common/style.css`、`src/common/core.js`：三章共用的樣式與引擎（分頁、一般／資優切換、投影模式、抽號、猜一猜、迷思擂台、分類小遊戲）
   - `src/ch5/tabs/t0.html … t8.html`：每個分頁的內容（第一行 `<!--NAV: 標題-->` 是分頁按鈕的名字）
   - `src/ch5/js/00_data.js`：所有「猜一猜」「迷思擂台」的題目
   - `src/ch5/js/t0.js … t8.js`：每個分頁的模擬程式
2. 重新組合：`cd src && python3 build.py ch5`
